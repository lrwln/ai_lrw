# 流式输出 streamble

一次性返回的，等待，
    复杂的计算 推理生成 耗时很久 
    如何优化？ 一个一个token推理生成 实时展示
    不用一次性给
    api 计算机网络协议底层理解
    chatbot 客户端 不断的拼接token 流式输出
    llm服务器和chatbot客户端 保持长连接 保持连接状态 不断发送token
    生成的token 流式输出 客户端 不断拼接 显示在界面上
llm chatbot 像人一样，实时输出 流式输出，等待用户输入，
ai产品的第一个关键用户体验

## 耗时
主要是推理所花费的时间和问题复杂度有关                  

##约定
- 服务器约定 接受 stream ：true 表示流式输出
- 客户端约定 发送 stream ：true 表示流式输出
